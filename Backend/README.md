# Tommy Fetch Agent

Tommy is a personal AI assistant for coding, study, and everyday questions. This
uAgent exposes Tommy through Fetch.ai's Agent Chat Protocol (ACP), publishes the
protocol manifest, and can connect to Agentverse through a mailbox. Responses are
generated by the existing Groq-backed Tommy assistant.

## Run locally

From the repository root, install the project requirements. Then change to the
`Backend` directory and configure the existing `GROQ_API_KEY` in `.env`. Set a
private, persistent seed phrase in your shell; do not commit it or share it:

```powershell
python -m pip install -r requirements.txt
cd Backend
$env:TOMMY_AGENT_SEED = "your-private-persistent-seed-phrase"
python tommy_fetch_agent.py
```

The agent starts on port `8001` by default. `TOMMY_AGENT_PORT` can override it.
Open the Agent Inspector URL printed in the terminal, connect the agent to an
Agentverse mailbox, and complete the mailbox setup in Agentverse. Keep the agent
running while testing ACP chat or ASI:One discovery.

The existing desktop app remains available through the root launcher (`python
..\a.py`) and runs independently from the Fetch agent.
